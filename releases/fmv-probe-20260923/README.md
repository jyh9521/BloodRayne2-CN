# BIK 过场字幕：开场 6 句验证包（2026-09-23）

> [!NOTE]
> 这是 2026-09-23 的早期 FMV 字幕显示验证记录（仅覆盖开场第一段视频）。完整的视频字幕与最新版汉化请参见根目录 [README.md](../../README.md)。

本包适用于 v12 汉化，仅覆盖 `video/A1S01P01_RU.srt`，不修改任何 POD、DLL、EXE、BIK 或配音文件。安装脚本会先校验 v12 的 `LANGUAGE.POD`、`dinput8.dll` 和 `rayne2.exe`。

## 手动测试步骤

1. 退出游戏，双击本目录 `INSTALL.cmd`（脚本会先完整备份现有的俄语槽字幕）。
2. 启动游戏并保持俄语语言入口，开启新游戏播放第一段预录过场。
3. 约 4.8 秒处应出现“准备好了吗？ 你今晚怎么这么安静？”。请顺带观察后续 5 句是否存在缺字、乱码或超出画面的情况，并确认英语配音未受影响。
4. 如需回退，退出游戏后双击本目录 `ROLLBACK.cmd` 即可恢复安装前的 SRT（包括此前自定义修改），不会撤销主体汉化。

> [!IMPORTANT]
> `source/A1S01P01_ZH.utf8.srt` 为可编辑中文源稿，`payload/video/A1S01P01_RU.srt` 为编译后的游戏载体编码文件。**请勿将 payload 另存为 UTF-8/GBK，也不要将 source 文件直接复制到游戏目录。**由于当前汉化使用自定义双字节字码映射位图字库，每次重新生成字库时都必须同步重新编译 SRT。
