# 全量预录过场中文字幕（v13 视频增量包，2026-09-25）

> [!NOTE]
> 这是 2026-09-25 的历史阶段发布记录。后续 2026-09-30 已对全部 15 个视频字幕重新打轴（见 [fmv-retime-20260930](../fmv-retime-20260930/README.md)），当前最新版整合包请参见根目录 [README.md](../../README.md)。

## 安装步骤

本包基于 v12 主体汉化增量升级，可保留此前已安装的开场字幕测试包，**无需先运行旧版 `RESTORE_PURE.cmd`**。

1. 退出游戏。
2. 双击本目录 `INSTALL.cmd`（脚本会先备份旧文件，再执行升级）。
3. 启动游戏，保持俄语语言入口（配音仍走英语资源）。
4. 重点测试开场宴会的长句、回忆片段及后续过场，确认中文字幕、换行与配音正常。

> [!TIP]
> 本目录脚本默认位于游戏目录下的 `_cn_project/releases/fmv-full-20260925`。ZIP 压缩包按游戏根目录结构打包，请解压至游戏根目录后再运行 `INSTALL.cmd`，不要单独移动脚本。

## 更新内容

- 覆盖全部 **15 部**带外置字幕的剧情视频，共 **222 条**中文字幕。
- 修正开场句读（例如“是啊，今晚恐怕会有不少人死得很惨。”、“别担心，有我帮你呢。”）。
- 按中文语义断句，清理沿袭外文的句间空格，保留合理的句号与标点。
- 人物、组织、武器和能力名称沿用项目术语表，附加术语见 `source/glossary.json`。
- 字库保留原有 1,725 字的编号并追加 **62 字**；菜单、招式表、实时剧情文本与英文演职员表原始条目保持不变。
- 新增视频专用换行钩子：按完整双字节字码断行，并避免逗号、句号等出现在行首或左引号出现在行尾；其他界面不经过该钩子。

## 修改文件与 Mod 兼容

- **替换 / 新增**：`LANGUAGE.POD`、`dinput8.dll` 以及 `video/` 下的 15 个 `*_RU.srt`。
- **保持不变**：`W32ART.POD`、`W32ENSND.POD`、磁盘上的 `rayne2.exe`、所有 `.bik` 视频、其他语言 SRT 及配音资源。
- `LANGUAGE.POD` 仅更新了 `ART\GOTHICTITLE_RU.TEX` 字库贴图，其余 387 个条目与 v12 完全一致。
- 若同时使用包含同名 DLL 或 `LANGUAGE.POD` 的其他补丁，仍需手动合并；运行时钩子仅针对已核对的纯净 `rayne2.exe`。

## 回滚方式

退出游戏并双击本目录 `ROLLBACK.cmd`，即可从 `_cn_project/test_backup/fmv_full_20260925` 还原安装前的主体与字幕文件，并移除原先不存在的 SRT。如果脚本检测到安装后有手动修改，会自动停止以防覆盖。

如需完全卸载汉化，请按顺序先回滚本视频增量包，再依次回滚早期的开场测试包和 v12 主体，切勿跳过增量包直接运行旧主体恢复脚本。

## 源稿与时间轴说明

- `source/*_ZH.utf8.srt` 与 `source/subtitles_zh.json` 为可读中文源稿；游戏实际加载的是 `payload/video/*_RU.srt` 的自定义字码版本。
- **请勿将编译后的字幕另存为 UTF-8/GBK，也不要直接把 UTF-8 源稿复制进游戏。** 更新字库时必须同步重新编译字幕。
- 第一部影片沿用已验证的时间轴；其余 14 部暂沿用游戏附带法语 SRT 的时间轴，并以法语为主要参考、意大利语等作辅助核对。原文件存在的少量时间重叠或过短提示记录在 `timing_review.json`，待后续按英语配音实机听测调整。
- `demo.bik`、`logos.bik`、`PROLOG.bik`、`ziggurat.bik` 原版没有配套外置字幕，本包未为其新增字幕（暂未排查画面内是否含可译文字）。
- 本次构建未启动游戏或自动安装，除开场显示路径已有截图确认外，其余影片及长句换行效果仍待实机测试。
